# Memory lifecycle audit

Use this reference when selected memory operations require traceable completion evidence.

## Decision method

Define memory-specific source/derived IDs, operation/reason, provenance and correction/deletion/consolidation completion plus post-change retrieval checks.

Map these semantics to approved common event fields and actual vendor events under existing access/retention policy.

Keep common capture-schema changes with their telemetry owner; record permitted-history and raw/derived deletion completion for the obligation reviewer.
