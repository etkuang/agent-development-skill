# Capability discovery selection

Use this reference when a large catalogue or observed selection errors justify deferred loading.

## Decision method

Compare direct capability selection with deferred definitions or candidate retrieval against measured context pressure and selection error.

Test candidate recall, harmful selection, complete task outcomes and added latency/cost. Catalogue retrieval quality is a different measure from document-evidence retrieval.

Choose the simplest sufficient discovery mechanism. A particular retrieval funnel is an implementation example, and a small catalogue need not introduce an index.
