# Real-task acceptance seed

## Selection method

1. Choose a small set of real examples covering priority tasks and meaningful variation.
2. Describe the acceptable end state and required or prohibited constraints for each example.
3. Check actual task completion separately from how clearly the result is communicated; leave later dataset expansion and scoring to evaluation design.

## Supporting guidance and sources

Start with a small real-task seed. Evaluate actual end states and required constraints separately from communication quality; a fluent completion claim is insufficient evidence. A fixed 50-case quota is unnecessary at this stage. [Anthropic agent-evaluation guide](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) (2026-01-09) and [OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices) (current API guide), accessed 2026-10-10.
