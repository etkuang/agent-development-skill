# Citation output binding

Use this reference when source-dependent claims must travel through a supported output mode.

## Decision method

Bind factual claims to authorized source IDs, versions, locators and visible passages, and check both record existence and actual support.

Choose a citation channel compatible with the output mechanism. Where a provider's native citation blocks cannot combine with strict JSON, use a supported rendering or explicit structured evidence references and validate them.

Preserve uncertainty and qualifications. Dialogue and another model's response can guide work without becoming authoritative evidence.
