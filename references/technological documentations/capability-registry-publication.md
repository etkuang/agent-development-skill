# Capability registry publication

Use this reference when a selected registry, discovery index or routing rule needs synchronization.

## Decision method

Publish approved authored tool/Skill versions with a named synchronization owner and separate catalogue/index/rule IDs.

Verify advertised capabilities match deployed availability. Select task/selection/latency/cost checks, adding candidate recall only for retrieval-based discovery.

Route authored Skill content/metadata changes to 6.5, tool metadata/contracts to 3.2, and discovery-design changes to 2.6. Submit publication/rule evidence to the release manifest and tested restoration path rather than creating another authoring policy.
