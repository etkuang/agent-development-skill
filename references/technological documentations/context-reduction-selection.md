# Context reduction selection

Use this reference when context growth requires a preservation strategy.

## Decision method

Compare no reduction with trimming, summarization, provider compaction and reference/offload approaches against the project's continuity requirement.

Identify task identifiers, constraints, corrections, decisions, verified action outcomes, pending work and source pointers that must survive. Test continuation on representative long tasks, including refetch availability and permitted retention.

Keep a summary's origin and source references. Full-history coverage requirements need explicit continuity/coverage evidence rather than an implicit size cutoff. Select semantic preservation here; numerical triggers follow measured growth and charges.
