# Agent-memory need assessment

## Selection method

1. Identify facts or preferences the agent must intentionally recall across sessions.
2. Check whether ordinary chat history, request state, checkpoints or reusable evidence already meet the need.
3. Include memory only for the remaining recall purpose, within the approved access and data constraints; design its contents and controls later.

## Supporting guidance and sources

Intentional cross-session agent recall differs from reading stored chat history, reusing session evidence or resuming checkpointed work. Establish the recall need before designing content, retention, correction, deletion and trust controls.
