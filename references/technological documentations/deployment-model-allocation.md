# Deployment model allocation

Use this reference when a changed model/effort route is proposed for production workloads.

## Decision method

Compare a fixed approved baseline with candidate allocation on the same ordinary, hard and high-impact tasks.

Measure router overhead, category mistakes, escalation, quality, tail latency and cost per success; preserve authorized direct/stronger routes where needed.

Pin fixture/environment, runner, expected evidence and pre-exposure gate. Keep changed allocations provisional until executed acceptance passes. An unchanged fixed model does not need a router experiment.
