# Answer evidence traceability

## Selection method

1. Identify which material claims require evidence and which source locators the user can inspect.
2. Check whether cited source text supports the specific claim, independently of whether the source is permitted or accepted.
3. Choose the answer outcome when support is missing; do not substitute a confident completion claim for evidence.

## Supporting guidance and sources

Claim support must be traceable to source text. Source acceptance and access permission do not themselves establish support for a particular answer; insufficient support changes the response outcome.
