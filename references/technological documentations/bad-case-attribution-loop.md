# Bad-case attribution loop

Use this reference when feedback or alerts propose an agent defect.

## Decision method

Admit permitted feedback with trace/source/release links, urgent/routine ownership and a reviewed disposition. Corroborate abandonment, repeated requests or negative clicks with task outcomes.

Inspect data/labels, evidence, prompt/model, routes, tools, state, policy and grader before assigning a cause, owner and remedy.

Track issue, reproducible case, cause, fix, evaluation, release and observed outcome. Submit reviewed fixtures through the canonical case admission path; training is conditional on an approved remedy.
