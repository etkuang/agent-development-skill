# Integration and model role selection

Use this reference when selecting capabilities, providers and model assignments.

## Decision method

Distinguish procedure, application function, direct API, provider-hosted tool and MCP transport from the trusted executor. Catalogue services and subordinate adapters/providers at their actual levels.

Compare one shared model/effort assignment with justified separation on representative quality, latency, cost and failures. Check exact model, endpoint, account, region and local/hosted feature support.

Use required live/snapshot access, source/version/locator metadata and write/outcome guarantees as selection constraints. Documented support and benchmark rankings do not establish workload suitability.

When a candidate's access or retirement affects the operating period, consult [provider lifecycle and availability](provider-lifecycle-availability-check.md). When selecting delegation across a system boundary, consult [remote agent integration](remote-agent-integration-selection.md); the integration catalogue owns that selection.
