# Human handoff policy

## Selection method

1. Identify the task conditions that need a human recipient and the role permitted to handle them.
2. Select the minimum task context that lets that recipient continue: goal, verified and attempted work, blocker, pending decision and evidence references.
3. Check the transfer against the approved data and access policies; keep the user informed of the referral outcome.

## Supporting guidance and sources

A handoff should carry permitted task context rather than raw dialogue by default. [Amazon Connect escalation](https://docs.aws.amazon.com/connect/latest/adminguide/agentic-self-service.html) (Amazon Connect, rolling documentation) and [Copilot Studio live handoff](https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-hand-off) (Copilot Studio, rolling documentation), source access recorded 2026-10-10.
