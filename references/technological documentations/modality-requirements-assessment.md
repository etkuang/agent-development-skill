# Modality requirements assessment

## Selection method

1. Identify the input and output modalities required by each task.
2. Check the supported model/API modalities and representative task results.
3. Consider customization only for a demonstrated capability gap; using an image or audio API does not by itself require a custom encoder or training.

## Supporting guidance and sources

Check supported model and API modalities and task results before proposing custom encoders, adapters or training. CLIP, ViT and Q-Former routes are candidates for justified customization, not prerequisites to multimodal use. [OpenAI image and vision](https://developers.openai.com/api/docs/guides/images-vision) and [audio](https://developers.openai.com/api/docs/guides/audio) (OpenAI API v1 current), accessed 2026-10-10.
