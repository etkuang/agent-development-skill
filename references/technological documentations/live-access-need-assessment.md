# Live-access need assessment

## Selection method

1. Identify the live data or external action that the task requires.
2. Check resource access, action authority, freshness and service-boundary constraints.
3. Include the required capability without prematurely choosing a connector or protocol; compare those options during integration design.

## Supporting guidance and sources

Live connectivity can use application functions, direct APIs, provider tools or MCP; select the integration only after the required capability is clear. [OpenAI plugin architecture](https://developers.openai.com/plugins/concepts/plugins) (current) and [OpenAI Agents SDK tools](https://openai.github.io/openai-agents-python/tools/) (current), accessed 2026-10-10.
