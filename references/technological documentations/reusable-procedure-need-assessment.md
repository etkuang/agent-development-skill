# Reusable-procedure need assessment

## Selection method

1. Identify repeated task instructions or procedures whose reuse would improve the scoped work.
2. Compare a reusable instruction/resource package with an ordinary prompt or fixed workflow.
3. Add discovery or routing only when selecting the appropriate procedure is itself a demonstrated task need.

## Supporting guidance and sources

A reusable procedure and live access address separate needs. A Skill can bundle instructions and resources; it does not by itself justify a router. Selection or discovery problems must justify added routing.
